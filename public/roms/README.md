# Bundled NES ROMs

Place `game1.nes` and `game2.nes` here to power the two "Retro Game" Wii
Menu tiles (currently marked "soon" in `src/screen/channels.ts` until these
files exist — flip their `status` to `"ready"` once added).

**Only put files here that are explicitly, verifiably free to redistribute**
— public domain, CC0, or homebrew explicitly released under a free license
by its author. Never add a commercial/copyrighted ROM (including old
console games still under copyright, which is virtually all of them).

The general "NES Channel" (upload) doesn't need anything here — it lets a
player load their own ROM file directly in the browser, nothing is stored
in this repo for that path.
